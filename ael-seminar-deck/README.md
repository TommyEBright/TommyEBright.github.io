# The AEL Study (SESD55 seminar)

Three interactive slides that introduce the accentuated eccentric loading (AEL) jump study before the Excel data analysis seminar.

1. What AEL is and how it is used, with a load-by-phase chart (normal, LOADED, AEL; 20/30/40% body weight).
2. An animated Santa-style athlete on a force plate (no arm swing, arm swing, LOADED, AEL) with a synced, illustrative force–time trace and phase-by-phase notes. Jump heights in the animation are identical on purpose.
3. The study design and a drag-the-bars prediction chart (kept in the viewer's browser only).

No participant data or results are in this folder. The student data files live on Canvas.
Keys: → / Space next, ← back, S presenter view, O overview, F full screen. `?handout` prints the slides with notes.
