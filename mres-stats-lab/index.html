R scripts for Stages 10–11

Download, open in RStudio and run line by line. Both scripts read the JASP Data Library files directly from JASP's GitHub repository.

  • stage7-jasp-to-r.R: every JASP analysis reproduced in R, classical and Bayesian (t-tests, binomial, ANOVA, regression, TOST, Bayes factors, ggplot2).
  • stage8-brms.R: Bayesian regression in brms with priors, MCMC diagnostics, posterior predictive checks and LOO.

Built for MRes students as an open educational companion to Lakens, D. (2022) Improving Your Statistical Inferences (CC BY-NC-SA 4.0). Datasets: JASP Data Library. Everything runs in your browser; nothing is tracked or stored.
