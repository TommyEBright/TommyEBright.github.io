Model comparison with leave-one-out cross-validation (LOO)

Bayesian regression fitted in your browser, with PSIS-LOO and Pareto k computed by the same algorithm as R's loo package. Drag points to see what changes.

Predict first. A more complex model (here, adding x²) always fits the data you have at least as well. Will it also always predict a new person better?
Check your prediction
No. LOO estimates out-of-sample prediction: for each person, how well does a model fitted to everyone else predict them? Extra parameters that only chase noise make predictions worse. The score is elpd (expected log predictive density); higher is better. Compare models using the difference in elpd and its standard error, not R².

How to read this table

elpd_loo: total log predictive density for left-out people (higher is better). p_loo: the effective number of parameters; if it is much larger than the real number of parameters, something is wrong. elpd_diff: each model compared with the best (top) model, with the se_diff of that difference.

A common rule of thumb (Vehtari and colleagues): if |elpd_diff| < 4 the models predict about equally well, so prefer the simpler or more theoretically sensible one. Otherwise, a difference several times larger than se_diff is convincing.

Pointwise elpd for y ~ x

Bars = PSIS-LOO estimate per person; dots = exact LOO (refitting without that person). They agree when k̂ is small.

Pareto k̂ diagnostic

k̂ > 0.7 means that leaving this person out changes the posterior so much that the fast PSIS approximation cannot be trusted. Use loo(fit, moment_match = TRUE) or reloo = TRUE, or rethink the model (for example, Student-t errors).

Try these

  1. With the simulated data, which model wins? Is the quadratic model's advantage (or disadvantage) larger than 4 elpd, and larger than its se_diff?
  2. Load the JASP steps → BMI data. Compare the table with the brms output on the Canvas page: elpd_loo = −273.7 (SE 6.7) for BMI ~ PA, with the linear and quadratic models within 1 elpd of each other and the intercept-only model about 7.6 behind. Small differences are expected, because brms uses slightly different priors and its own random draws.
  3. Press Create an influential outlier. Which person gets k̂ > 0.7, and how does their pointwise elpd compare with everyone else's?
  4. Drag a point from the middle of the x-range up and down. Its k̂ hardly changes, but dragging an edge point does change it. Why? (Think back to leverage in Stage 7.)
