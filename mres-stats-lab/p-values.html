Which p-values should you expect?

Simulate thousands of two-group studies and watch the distribution of p-values. Based on Lakens, chapter 1.

Predict first. Set the true effect to d = 0 (no effect at all). If you ran 1,000 studies, what shape would the histogram of p-values take? Write your answer down, then press Run 1,000.
Check your prediction
When the null hypothesis is true, the histogram is flat. Every p-value is equally likely, so about 5% of studies land below .05. That 5% is the Type I error rate you chose with α.

When d = 0, "% significant" is your Type I error rate. When d > 0 it estimates your power. "True power" is calculated exactly from the noncentral t distribution.

Try these, in order

  1. d = 0, n = 20. Run 1,000. Is the histogram flat? What % are significant?
  2. d = 0.5, n = 20. Run 1,000. The effect is real, but how often do you get p < .05? What does a non-significant result tell you here?
  3. d = 0.5, n = 100. Zoom in to 0–.05. Are p-values between .04 and .05 common or rare? Compare the orange line with the grey line in that last bin.
  4. d = 0.5, n = 200. Zoom in again. In the .04–.05 bin, is the orange line (H1 true) below the grey line (H0 true)? If so, a p of .045 is more likely when there is no effect. This is Lindley's paradox.
What should you take away?

The p-value distribution depends on power. With no effect it is flat; with high power it piles up close to zero. A single p-value is a noisy draw from this distribution. That is why one p = .03 should not convince you of much, and why a non-significant result from a low-powered study is not evidence that there is no effect.
