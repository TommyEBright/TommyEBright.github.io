Show the data: what your plot hides

Identical means and SDs can hide very different data. Choose a plot type and see what it reveals.

Predict first. All four groups have mean = 50.0 and SD = 10.0. Start with the bar chart. Do the groups differ? Then switch to the other plot types.
What did you find?
The bar chart (the "dynamite plot") shows four identical bars. Group B is really two subgroups, group C is strongly skewed, and group D is a tight cluster plus two extreme values. Only plots that show individual data points, or the full distribution, reveal this. Journals increasingly ask for them (Weissgerber et al., 2015).

In JASP: Descriptives → Basic plots and Customizable plots give you boxplots with jittered points, violin plots and raincloud plots. The t-test and ANOVA dialogs also have Raincloud plots under Plots. See the official JASP raincloud video on the Canvas page.
In R (ggplot2): geom_jitter(), geom_boxplot(), geom_violin(), or ggdist::stat_halfeye() for rainclouds. The code is in Stage 8 of the Canvas page.
Predict first. Four datasets have the same means, SDs, correlation (r = .82) and regression line (ŷ = 3.00 + 0.50x). Would you be happy reporting the same regression for all four?
Reveal
No. Only dataset I suits a linear regression. II is curved, III has one outlier that changes the slope, and IV's slope depends entirely on a single point with high leverage. Same numbers, different stories: always plot first. JASP's Data Library has Anscombe's Quartet and the Datasaurus Dozen (12 sets with identical statistics) so you can try this yourself.
