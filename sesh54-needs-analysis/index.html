Private by design

Everything runs in your browser using transparent rules. There is no AI model, no server and no API calls, and your writing is never stored or sent anywhere. Your notes are saved only in this browser on this device, and "Clear my data" removes them. If you upload a .docx file, the tool downloads a small open-source reader (mammoth.js) to read the file on your device. Your file itself is never uploaded.
